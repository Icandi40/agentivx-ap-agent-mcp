# Live sandbox sample files

Synthetic sample data for the first live run against a QuickBooks Online **sandbox** company.
Tim Philip Masonry and PO 1002 come from Intuit's sandbox sample company. The invoices and the
receiving log were written for this test. None of this is a real bill or a real business.

- `tpm-24117-clean.txt`: matches PO 1002 and the receiving log
- `tpm-24117-resent.txt`: the same invoice sent again
- `tpm-24118-price-variance.txt`: same item, billed at $137.50 against a PO price of $125.00
- `receiving-log.csv`: what arrived against PO 1002
